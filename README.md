## Краткое описание

Полноценный бизнес-план интернет-магазина с прототипом сайта для продажи персонализированных десертов без сахара и глютена. Проект включает анализ рынка, финансовую модель, маркетинговую стратегию, SEO-ядро, оценку рисков и интерактивный конструктор десертов на лендинге.

Проект разработан в рамках курса «Цифровой бизнес» и демонстрирует навыки бизнес-аналитика: от идеи и анализа до экономического обоснования и веб-прототипа.

## Что внутри

- **Бизнес-план** — полный документ с резюме, анализом отрасли, SWOT, маркетинговым планом (4P), организационной структурой, финансовым планом и оценкой рисков.
- **Финансовая модель** — расчёты в Project Expert: NPV ~ 0,28 млн ₽, IRR ~ 28 %, PI ~ 1,2, срок окупаемости — 22 месяца.
- **Семантическое ядро** — подбор 70+ ключевых запросов (ВЧ, СЧ, НЧ) для SEO-продвижения.
- **Прототип сайта** — одностраничный лендинг с конструктором десертов, каталогом наборов SweetBox, корзиной и описанием подписки (HTML/CSS/JS).
- **Презентация** — слайды для защиты проекта перед инвесторами/преподавателем.
